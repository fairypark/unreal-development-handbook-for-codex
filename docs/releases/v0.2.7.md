# v0.2.7 — Bounded prototype workflow guidance

This release turns the evidence-backed prototype-loop investigation into
durable Handbook guidance for future Unreal tasks. It improves the workflow
contract itself; it does not promote any test level or bundle Editor-control
operations.

## Included

- Added bounded-edit, diagnostic-audit, promotion-review, and separately
  confirmed maintenance-rebuild boundaries.
- Added batch and round-trip economics, complete-operation budgets,
  state-audit-before-retry, and operational telemetry guidance.
- Separated workflow release from level or system promotion.
- Added an anonymized case study and regression coverage for the latency and
  gate-state rules.
- Preserved the existing staged world-design, reference-to-prototype, camera
  authority, and dependent-strata contracts while generalizing the new rules.

## Validation

- Handbook test suite: 20 tests passed.
- Reference-to-Prototype contract template: valid.
- Official Plugin validator passed.
- Official validators passed for all six changed Handbook Skills.
- Secret scan and `git diff --check` passed.

The release is a Handbook/plugin workflow improvement. It makes no claim that
any particular level has completed production promotion.
