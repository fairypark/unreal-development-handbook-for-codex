# v0.2.3 — Mandatory staged AI level-production workflow

This patch release makes the documented level-production workflow a required execution contract for AI-led Unreal level work.

- A mandatory Chapter 04 workflow contract covering stage order, workflow records, handoff evidence, promotion status, stop conditions, rollback, and gate reopening.
- An explicit route-authority sub-gate between macro blockout and playable blockout, with required corridor and traversal evidence.
- Cross-references in Chapter 15 and the related Skills so AI cannot silently skip level stages or treat Tool success as promotion evidence.
- Updated Skill metadata and plugin version `0.2.3`.
