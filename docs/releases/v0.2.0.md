# v0.2.0 — Foundational Handbook plugin

This is the first public plugin release of **Unreal Development Handbook for Codex**.

## Included

- The authoritative project charter covering mission, design-first and validation-first principles, writing standards, AI behavior, the Editor Skills boundary, research mindset, and long-term goals.
- Nine progressively loaded Skills backed by seventeen canonical chapters.
- Reasoning coverage for project and gameplay architecture, worlds and levels, content and assets, Blueprint and C++, automation and PCG, rendering, performance, validation, production, collaboration, AI-assisted development, and case analysis.
- A fail-soft relationship with **Unreal Editor Skills for Codex**: either plugin works alone, and both cooperate when installed.
- Read-only plugin capabilities with no MCP server, Editor hook, or live mutation tool bundled.

## Distribution

The plugin is available through the Fairypark marketplace hosted by `fairypark/unreal-editor-skills-for-codex`. Restart the desktop app and begin a new task after installation so the Handbook Skills are discovered.
