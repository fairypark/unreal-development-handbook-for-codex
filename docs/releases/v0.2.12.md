# v0.2.12 — Layered AI-assisted world-building guidance

This release turns the reviewed AI-assisted Unreal world-building
demonstration into durable Handbook guidance without treating a capability
demo as production evidence. It strengthens agent-facing architecture,
procedural authorship, spatial validation, human oversight, and applied case
reasoning while keeping version-specific Unreal MCP details in dated research
context.

## Included

- Expanded Chapter 02 API guidance with non-mutating get/list/inspect parity,
  typed units and side effects, explicit empty-result semantics, partial-state
  reporting, and actionable recovery errors.
- Added progressive capability discovery and scoped schema caching to Chapter
  08 so automation loads only the required operational surface and refreshes
  stale version or capability descriptions.
- Added Chapter 09 contracts for persistent parametric systems, instant
  one-off generation, and direct-authored content, including ownership,
  persistence, cleanup, rollback, regeneration, and reclassification rules.
- Added an AI-assisted spatial uncertainty taxonomy covering pivots,
  orientation, final transformed bounds, overlap, grounding, and gameplay,
  navigation, camera, and maintenance clearance before broad scaling.
- Added a Chapter 15 context-acquisition ladder that prioritizes explicit
  targets and approved project examples before semantic search, bounded
  discovery, or temporary inspection scripts.
- Formalized Toolset or capability surface, Primitive, Example, and Skill as
  separate knowledge and authority layers, with progressive discovery and
  observation parity for mutation interfaces.
- Separated builder screenshot-guided self-inspection from independent
  evaluation and promotion in Chapters 12 and 15. Manual corrections now
  remain tracked exceptions or generator feedback rather than retrospective
  proof that the original result passed.
- Added a Chapter 16 `PENDING_EVIDENCE` investigation note for the demonstration
  with explicit gaps for baselines, traces, failure rates, time and cost,
  persistence, source control, regeneration, overrides, runtime performance,
  independent review, and team maintenance outcomes.
- Added regression tests for the new canonical responsibilities and evidence
  boundaries.
