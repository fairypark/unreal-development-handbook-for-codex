# v0.2.18 — UE 5.8 사례와 5.9 프리뷰 적용 범위

UE 5.8에서 확인한 초지 보행과 UE 5.8.3 PCG 학습 장면의 결과를 보존하고, 5.9 MegaJam Preview에서 직접 시험한 내용과 프로젝트별로 확인할 부분을 9개 장에 반영했습니다. 한국어 검토본에는 각 결정에 필요한 최소 시험과 Epic 출처가 있습니다. [한국어 검토본](https://github.com/fairypark/unreal-development-handbook-for-codex/blob/v0.2.18/skills/validate-unreal-production/references/ue-5-9-preview.ko.md)

- **실제 5.9 시험.** Windows의 UE 5.9.0 CL 60351404에서 Python으로 Actor Blueprint를 복제하고, 복제본에 빈 함수 그래프를 추가해 컴파일하고 저장했습니다. 새 에디터 프로세스에서도 복제본만 해당 함수를 가졌고 다시 컴파일됐습니다. 새 프로젝트에서 반복한 최종 두 실행 모두 오류와 경고가 없었습니다.
- **프로젝트에서 확인할 항목.** AI 가공 화면과 같은 카메라의 실제 게임 화면, MCP 연결과 편집 도구의 가용성, Lumen World Cache를 끄고 켰을 때의 비용, 브라우저 새로고침 후 체크포인트와 보상, 지형·식생의 접지와 거리별 비용, PCG Paint 즉시 갱신과 저장 후 배치를 구체적인 비교로 설명했습니다. 이 항목들의 프로젝트 동작은 이번 릴리즈에서 측정하지 않았습니다.
- **출처와 검증.** Horde를 포함한 과거 근거의 링크가 Epic 문서 5.8판을 여는지 확인했습니다. 회귀 테스트 59개, 두 계약 템플릿, 플러그인과 스킬 9개, 변경 문서의 로컬 링크와 앵커를 검증했습니다.
