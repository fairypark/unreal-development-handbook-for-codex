# v0.2.15 — Collaborative environment requirements

환경 제작자가 원하는 경험과 화면을 구체화할 수 있도록 질문, 대안, 추천 방향을 함께 제시하는 요구사항 대화 지침을 추가했습니다.

## 변경 내용

- Chapter 04에 경험과 정서, 참고 자료의 우선순위, 시점과 주인공, 식생과 빈 공간, 지면과 접촉, 에셋 적합성, 작업 범위를 구체화하는 질문 예시를 추가했습니다.
- 미정인 방향에는 구체적인 대안과 추천 이유, 장단점, 확인할 관찰을 제시하고, 답을 기존 브리프의 관찰 가능한 수용 기준으로 옮기도록 했습니다.
- Chapter 15와 두 Skill 진입점에 대화 지침을 연결하고, 동등한 내용을 담은 한국어 검토본을 함께 제공합니다.
- 기존 답변과 승인된 국소 수정은 계승합니다. 질문 전체를 필수 설문으로 만들거나 질문마다 새 게이트를 만들지 않으며, 무응답이나 기본 선택을 승인으로 간주하지 않습니다.
- 이미 공개된 v0.2.14를 계승하고 이번 릴리즈를 `main`에 통합합니다.

## 검증과 적용 범위

- Handbook 회귀 검사 49개 통과 (`jsonschema` 활성화).
- 공식 Plugin validator 및 변경한 Skill 2개의 공식 Skill validator 통과.
- 로컬 문서 링크·앵커, `git diff --check`, 구성된 비밀정보 검사 통과.
- Plugin validator는 Codex에서 해당 도구가 제거되기 직전의 [공식 리비전 985cf47](https://github.com/openai/codex/tree/985cf47a4eb6084b2ff6b30ebdb1216acda85bb4/codex-rs/skills/src/assets/samples/plugin-creator)을 사용했습니다.

검증 범위는 문서 구조, 플러그인 패키지 및 기존 회귀 검사입니다. 새 대화 방식의 실제 제작 성과나 시각 품질 향상은 아직 실사용으로 검증하지 않았습니다. Unreal 프로젝트의 레벨이나 Editor 상태는 이번 릴리즈의 변경 대상이 아닙니다.
