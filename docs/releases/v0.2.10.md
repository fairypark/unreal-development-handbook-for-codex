# v0.2.10 — PCG Manual Edit override lifecycle guidance

This patch release connects Unreal Engine 5.8's PCG Manual Edit and Data
Override System to the Handbook's existing procedural-base and override
lifecycle contract. It keeps the Handbook focused on durable reasoning rather
than Editor operation or API instructions.

## Included

- Added a version-specific application note to Chapter 09 explaining that
  Manual Edit changes are a delta layer over a versioned procedural base, not a
  replacement source of truth.
- Required stable target identity or mapping policy, graph and input
  provenance, scope, intent, ownership, approval, rollback, and revalidation
  before promoting a manual override.
- Required orphan and conflict classification during regeneration instead of
  silently baking, erasing, or duplicating an override.
- Recorded the UE 5.8 Data Override System and PCG Editor Mode maturity risk and
  the need to validate persistence, regeneration, source-control behavior,
  performance, and fallback under the target build.
- Added a regression test for the new lifecycle connection without adding
  version-specific UI, API, or Editor-operation instructions.
