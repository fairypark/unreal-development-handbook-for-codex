# v0.2.16 — Source capability and reusable environment systems

초지 제작에서 확인한 소스 진단과 재사용 판단을 콘텐츠 아키텍처, 절차적 시스템, 렌더링, 사례 연구에 반영했습니다. 실행 절차는 Editor Skills v0.4.5에서 다룹니다.

## 변경 내용

- 소스 형태, 표면 반응, 장면 내 조합을 구분하고 실제 역할·후면·크기·최종 외곽을 검사합니다. 재질만 수정할 때 유효한 형태 증거를 재사용하되 관련 장면 회귀는 확인합니다.
- 바닥과 식생의 연결이 필요한 콘셉트에 공유 공간 데이터의 식별자·좌표·단위·버전과 소비자별 매핑을 정의합니다. 같은 수식을 쓰는 사실과 실제 소비자 샘플의 수치 일치를 구분합니다.
- 완성 소스를 자체 제작, 외부 의존 프리셋, 맵 전용 예제로 분류하고 원본 보존, 의존성, 복제 검증, 새 맵 재검증의 책임을 설명합니다.
- 레이어별 색 보정, 식생의 형태·저장된 노멀·투과광 진단과 조건부 캡처 증거의 적용 한계를 보강했습니다.
- 실패와 수정 범위, 독립 판정, 미검증 항목을 포함한 초지 사례 및 대응 한국어 검토본을 추가했습니다. 사례의 배합·밀도·조명 수치를 보편적인 기본값으로 만들지 않습니다.

## 검증과 적용 범위

- Handbook 회귀 검사 49개 통과 (`jsonschema` 활성화).
- 공식 Plugin validator와 9개 Skill의 공식 Skill validator 통과.
- 변경 문서의 로컬 링크·앵커, JSON 파싱, `git diff --check`, 구성된 비밀정보 검사 통과.
- 독립 읽기 전용 검토에서 재질 전용 수정, 새 맵 재사용, 캡처 권한과 샘플 검증의 범위를 확인했습니다.
- Plugin validator는 기존 릴리즈와 같은 [공식 OpenAI 리비전 985cf47](https://github.com/openai/codex/tree/985cf47a4eb6084b2ff6b30ebdb1216acda85bb4/codex-rs/skills/src/assets/samples/plugin-creator)을 사용했습니다.

사례의 원본 이미지·엔진 기록과 Unreal 에셋은 공개 패키지에 포함하지 않습니다. 사례의 관찰은 Editor 수준이며, 실제 CPU/GPU 필드 일치, 성능, 바람, 대상 플랫폼, cook 또는 다른 맵의 품질을 입증하지 않습니다. 새 지침의 인과적 품질 향상이나 시간 절감도 별도로 측정하지 않았습니다.
