# v0.2.1 — Route iteration and failure-learning update

This patch release adds evidence-backed guidance from a dense environment route-authoring failure and its spline pilot.

## Included

- A pending case-study investigation covering route-first blockout, route conflicts, spline representation, recovery, and evidence gaps.
- A route authority and continuous-corridor contract for world and level design.
- Explicit separation between route intent data, review visualization, and the playable or walkable surface.
- Spatial automation postconditions for topology, ownership, persistence, partial execution, and ambiguous tool results.
- Route-coupled PCG authority, versioned masks, lifecycle-state separation, and regeneration dependencies.
- An iteration learning record covering symptoms, causes, false assumptions, changed invariants, new checks, same-condition rechecks, and recurrence status.
