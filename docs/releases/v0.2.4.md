# v0.2.4 — Landscape-first outdoor level-design prototypes

This patch release clarifies the default ground representation for outdoor map level-design prototypes.

## Included

- Outdoor map level-design prototypes use a minimal Landscape terrain as the actual playable floor by default, including the first macro blockout and playable blockout.
- A flat cube or plane is not used as a speed shortcut when elevation, slopes, drainage, terrain transitions, grounding, or terrain contacts are part of the target experience.
- Another floor representation is allowed only when a specific user or stakeholder request explicitly overrides the default.
- Validation now checks movement, grounding, collision, route grade, and terrain contacts on the Landscape surface.
