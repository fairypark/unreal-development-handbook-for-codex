# v0.2.2 — Research-backed safety and architecture update

This patch release adds durable decision guidance for AI-assisted mutation, procedural exceptions, and network replication strategy selection.

## Included

- An AI mutation boundary and promotion contract covering observation, isolation, postconditions, independent evaluation, approval, provenance, rollback, and privileged editor-control boundaries.
- A procedural exception contract that separates generated bases from manual overrides and requires intent, ownership, source-generation provenance, conflict detection, revalidation, and rollback.
- A replication strategy matrix covering Generic Replication, Replication Graph, and Iris, with authority, relevancy, prediction, late-join, performance, migration, and fallback validation criteria.
- Version- and audience-aware Iris maturity guidance that distinguishes UE 5.8 licensee release notes from public opt-in or Experimental documentation.
- Official Epic source links and cross-references from the affected canonical chapters.
