# v0.2.17 — 사례로 익히는 Unreal 개발 판단

17개 장의 첫 부분에서 서로 다른 선택이 필요한 상황을 비교합니다. 각 사례는 어떤 조건이 선택을 바꾸는지, 가장 적은 비용으로 그 판단을 어떻게 확인할지 설명합니다. [한국어 장별 안내](https://github.com/fairypark/unreal-development-handbook-for-codex/blob/v0.2.17/skills/reason-about-unreal-development/references/case-based-judgment.ko.md)

- **월드와 PCG**. 개별 건물의 접지 검사를 통과했어도 도보로 이동할 때 목적지 사이가 비어 보였던 사례를 실었습니다. PCG 학습 장면에서는 가운데 지점이 지형에 닿아도 물체의 모서리가 뜰 수 있었던 관찰을 다룹니다. 두 사례 모두 당시 확인한 결과와 다음 장면에서 다시 시험할 조건을 표시했습니다.
- **성능과 배포**. 측정한 설정·실행 환경과 실제 전달한 빌드를 추적하는 기준을 보강했습니다. 저장 데이터 예시에서는 항구에서 업데이트하고 등대에 도착한 플레이어가 이전 버전으로 돌아갈 때, 어느 지점부터 이어갈 수 있고 이미 받은 보상이 유지되는지 확인합니다. [13장 예시](https://github.com/fairypark/unreal-development-handbook-for-codex/blob/v0.2.17/skills/validate-unreal-production/references/13-production-pipeline.md#can-players-keep-progress-made-after-an-update)
- **직접 연습하기**. 한국어와 영어로 각각 7쌍, 14문제를 제공합니다. 참가자 파일에는 질문과 응답 안내만 들어 있습니다. 평가자용 원본과 해설은 저장소에 있습니다. [한국어 질문 다운로드](https://github.com/fairypark/unreal-development-handbook-for-codex/releases/download/v0.2.17/judgment-questions.ko.json) · [영어 질문 다운로드](https://github.com/fairypark/unreal-development-handbook-for-codex/releases/download/v0.2.17/judgment-questions.en.json) · [한국어 평가 안내](https://github.com/fairypark/unreal-development-handbook-for-codex/blob/v0.2.17/skills/validate-unreal-production/references/judgment-evaluation.ko.md)

회귀 테스트 59개, 플러그인과 스킬 9개, 두 계약 템플릿, 변경 문서의 로컬 링크와 앵커를 검증했습니다. 두 다운로드 파일은 언어별 14개 문항과 평가자 필드 제외 여부를 확인했습니다.

이번 검증 범위는 핸드북과 연습 도구입니다. 실제 Unreal 빌드의 저장 마이그레이션·롤백, 독자의 판단력 변화, 게임 제작 품질 향상은 측정하지 않았습니다.
