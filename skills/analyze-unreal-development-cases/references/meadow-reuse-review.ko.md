# 초지 제작 사례와 재사용 원칙 — 한국어 검토본

대응 원문: [Chapter 16의 초지 사례](16-case-studies.md#case-recovering-a-meadow-through-source-capability-and-coupled-ground-cover), [Chapter 05](../../design-unreal-content-architecture/references/05-content-asset-architecture.md), [Chapter 09](../../design-unreal-automation-and-pcg/references/09-procedural-systems-pcg.md), [Chapter 10](../../validate-unreal-production/references/10-rendering.md).

## 의도와 문제

UE 5.8에서 초지, 독립된 바위 랜드마크, 얕은 개울, 열린 경로를 만들었다. 초기 잔디는 반복된 덩어리나 평평한 선처럼 보였고 바닥은 초록 판처럼 읽혔다. 절벽용 바위를 독립된 덩어리로 기울이자 열린 뒷면이 드러났다. 밀도 증가, 반복 색 보정, 조명으로 가리기 대신 실패한 소스와 시각 요소만 수정하고 승인된 지형·경로·카메라를 유지했다.

## 관찰된 결과

- 잔디 형태가 통과한 뒤에도 재질은 2/5였다. 동일한 36개 시험 위치에서 재질만 바꾼 후 적용 항목의 4/5 기준을 통과했다.
- 대표 구간의 총 2,762개 생태 인스턴스를 유지하면서 소스 형태·분포·일부 뿌리 위치를 수정했고 두 구간이 통과했다. 개수가 같아도 삼각형 수와 비용이 같다는 뜻은 아니다.
- 전체 확장 뒤 균등한 나무 줄 때문에 배치 2/5, 원경 깊이 3/5를 받았다. 기존의 나무 57개만 군집과 강조목으로 재배치한 뒤 두 항목이 4/5를 받았다.
- 최종 시각 회귀와 저장 후 재읽기, 17개 지점의 PIE 경로 검증을 완료했다. 보행 샘플 336개에서 Falling은 없었다. 패키지·대상 플랫폼·성능·바람·다른 프로젝트 재사용은 검증하지 않았다.

## 다음 작업에 적용할 결정

1. 기존 에셋 준비도 검사 안에서 소스 형태, 표면 반응, 장면 내 조합을 구분한다. 역할·크기·후면·최종 외곽을 검사하고 재질만 바뀌면 유효한 형태 검사를 재사용하되 관련 장면 회귀는 확인한다. 사용자 정의 메시 제작을 의무화하지 않는다.
2. 바닥과 식생의 연결이 필요한 콘셉트에서는 좌표계·단위·원점·시드·분포 버전·수동 강조점·소비자 매핑을 공유한다. 각각 다른 반응 곡선을 사용할 수 있으며 모든 초록 픽셀에 풀이 있어야 하는 것은 아니다. 경로·물가·바위 제외 규칙의 우선순위를 유지한다.
3. CPU와 GPU에서 같은 식을 사용해도 같은 결과라고 가정하지 않는다. 음수 좌표와 셀 경계를 포함해 같은 위치를 샘플링하고 사전 허용 오차로 비교한다. 이번 사례에서는 두 구현의 수치적 일치를 독립적으로 입증하지 않았다.
4. 잔디의 형태, 저장된 노멀, 앞뒷면 음영, 반사·투과광, 분포를 구분해 진단한다. 풀에만 필요한 색 보정이 흙에도 적용되지 않도록 레이어별 보정 후 혼합하고 순수 레이어와 전이부를 확인한다.
5. 완성된 소스를 라이브러리로 복제할 때 자체 제작, 외부 의존 프리셋, 맵 전용 예제를 구분한다. 원본·의존성·승인 범위·복제 검증·교체할 입력을 기록하고 새 맵에서 재검증한다.
6. 캡처 자체가 비교를 방해할 때는 예외 사유와 권한, 동일 카메라·렌더 조건, 원본 이미지, 시간·해시·안정성 증거를 보존한다. 다른 카메라의 진단 영수증으로 대체 이미지의 진위를 보증하지 않는다. 절차의 구체적인 구현은 Editor Skills에 둔다.

수치 배합, 특정 셰이더 보정, 조명값, 메시 표현 방식은 사례 값이다. 여러 수정의 개별 효과나 시간 절감은 측정하지 않았다. 원본 이미지와 엔진 기록은 운영자의 프로젝트에 보존되며 공개 핸드북에는 포함하지 않는다.
